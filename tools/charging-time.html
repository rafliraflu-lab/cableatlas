Method and limits

Energy added = Wh × change in state of charge. Divide by average input times efficiency. Charge taper, use during charging, and thermal protection can extend the result. Use measured average power if available.

Reference: https://www.usb.org/usb-charger-pd. Check exact device documentation for implementation details.

Calculations run in your browser; inputs are not submitted to a server by this tool.
