Mini DisplayPort

Small rectangular shell with rounded lower corners.

Typical use

Legacy laptop and display video connections.

What the form does not prove

Thunderbolt 1/2 use the same physical shape but not every port supports Thunderbolt.

Verification step

Check the host port icon and model specification.

Reference: https://www.displayport.org/faq/. Check exact device documentation for implementation details.
