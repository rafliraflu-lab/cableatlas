A USB speed matrix for mixed devices

Find the common data rate across endpoints.

Updated 18 November 2026 · By Saiful Bahri · Device-specific verification required

Worked example

A 20 Gbit/s source with a documented 5 Gbit/s cable and 10 Gbit/s destination has a nominal ceiling of 5 Gbit/s if a common mode is supported. If a device supports only a different USB lane configuration, the actual shared mode may be lower.

Repeatable check

Create a three-column inventory: source, cable, destination. Record the explicit USB generation or throughput marking for each. If the manufacturer publishes only connector shape, mark the value unknown. Then perform a controlled transfer test.

Interpret the result

Taking the minimum is an upper bound, not a negotiated rate. USB4 and Thunderbolt tunneling or asymmetric configurations require specification-specific checks.

Illustrative calculation or scenario, not an independent hardware test. Keep your own device records to verify the setup.
