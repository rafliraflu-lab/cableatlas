GB, GiB, Gbit/s and real transfer time

Avoid mixing bytes and bits when estimating transfers.

Updated 18 November 2026 · By Saiful Bahri · Device-specific verification required

Worked example

A 100 GB decimal file is 800 gigabits. At 5 Gbit/s, ideal time is 160 seconds. At 70% effective throughput it is 228.6 seconds. A 100 GiB file is 107.374 GB decimal and takes about 245 seconds at the same effective rate.

Repeatable check

Create or select a non-sensitive large file. Time a normal copy between known drives. Repeat using the same file and destination, then change only the USB port or cable. Consider cache and sustained write speed when interpreting results.

Interpret the result

The rated bus speed is not disk throughput. Small-file copies and encryption can produce very different results.

Illustrative calculation or scenario, not an independent hardware test. Keep your own device records to verify the setup.
